# Persona-Phase Map of GenAI Capabilities

## Overview
A table from an IBM internal course ("lk-course", hybrid cloud console
learning path) mapping generative AI capabilities to phases of the software
delivery lifecycle and the personas responsible at each phase.

## Key Points
- **Discovery and Design** — Business Analyst (Discover) and Architect
  (Generate): architecture diagrams, auto code conversion, cost estimates
  available at design time, design refactoring.
- **Develop and Test** — spans Developer, FinOps Consultant, Quality
  Engineer, Delivery/Project Manager, Knowledge Manager (Generate):
  Terraform code, Ansible playbooks, GitOps pipelines, reusable templates,
  certified images; plus unit test cases, end-to-end process execution,
  vulnerability scanning, compliance reports.
- **Deploy** — Platform Engineer and IT Shared Services (Generate); the
  source table lists this column heading but no specific activities under it.
- **ITOps and Automation** — Site Reliability Engineer and IT Shared
  Services (Perform): Transition Assist and corpus building, user/agent
  assistance, auto-triaging and ticket summarization, issue categorization,
  augmented root-cause analysis and ticket resolution, runbook generation,
  and RPA-augmented event/release management.
- **Source note**: a single HTML table (screen-reader/course markup), not
  prose — no accompanying narrative. The Deploy column's blank activities
  above reflect a gap in the source table itself, not truncation by ingest.
